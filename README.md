# Решение: «Матчи тура»

## Сколько заняло
Около 1 ч 15 мин.

## Что сделано и что не успел
- **Сделано:** экран `MatchesScreen` с карточками команд, счётом и русскими статусами; фильтры («Все», «Предстоящие», «Завершённые»); pull-to-refresh и ручное обновление с `UpdatedAgo`; локализация времени в часовом поясе устройства; поиск по клубу и городу (бонус); исправлены баги в `useFavorites` и `UpdatedAgo`.
- **Не успел:** сохранение избранного на диск через AsyncStorage при перезапуске (оставил хранение в памяти).

## Решения
- **Статусы:** `finished` → «Завершённые»; `scheduled` и `postponed` → «Предстоящие» (ещё не сыграны); `live` → отображается во «Все» и «Предстоящие» (актуальный матч текущего тура) с указанием минуты.
- **Особенности данных:**
  - Счёт `0:0`: проверяется строго через `typeof score.home === 'number'`, чтобы `0` не терялся из-за falsy-проверки.
  - Перенесённый матч (`startsAt: null`): безопасно выводится «Дата не определена» вместо падения парсера.
  - Плейсхолдер `OWNER/REPO` в `src/config.ts`: заменён на адрес рабочего репозитория.

## Баги из части 2
1. **Звёздочки:** `Boolean(favorites.indexOf(id))` возвращал `true` для отсутствующих элементов из-за `Boolean(-1)`. При первом добавлении (`index === 0`) получался `Boolean(0) === false` (звезда гасла). Плюс массив мутировался через `push`/`splice` напрямую без смены ссылки, из-за чего React пропускал ререндеры. Исправлено на `favorites.includes(id)` и иммутабельный сеттер.
2. **«Обновлено N сек назад»:** устаревшее замыкание (`seconds = 0`) в `setInterval` без зависимостей замораживало счётчик на `1`, таймер не сбрасывался при изменении `since`, а интервал не очищался (`clearInterval`). Исправлено вычислением реальной дельты от `since` и корректным cleanup-эффектом.

## Как я использовал ИИ
Использовал ассистента для драфта типов и стилей. Вручную исправил неточности модели: попытку проверять счёт через `if (score.home)` (терялся 0:0), отсутствие валидации `null` в `startsAt` и нерабочий URL в `config.ts`.
